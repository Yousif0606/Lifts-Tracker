# lift-tracker

A command-line tool for tracking progressive overload in the gym.

Set up your weekly workout split, log the weight you lift each session, and see
your progress over time as a percentage above your starting weight.

## Status

🚧 Work in progress — building it out.

## Planned features

- Set up a workout split for each day of the week (Mon–Sun)
- Log the weight lifted per exercise, saved between sessions
- Track progress from your starting (baseline) weight
- View progressive-overload percentage over time

## Usage

```sh
python3 main.py
```

## Built with

Python 3 — no external dependencies.
